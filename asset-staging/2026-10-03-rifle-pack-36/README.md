# Rifle Pack36 provenance

User authorized generation and integration together. Built-in image_gen created
three transparent raster sources and revised the reload source for continuous
forearms. Exact prompts: prompts.json and prompts-v2.json. The original
reload-source.png is retained for recovery; active source is reload-source-v2.png.
Runtime mapping, exact source windows, dimensions, alpha, budgets, muzzle point,
bore angle, sequences and SHA256 are owned by manifest.json.

Ready is cell5 of the same normalized six-pose action source. Runtime assets are
derived alpha-WebP, not the raw source sheets. Reticle/optic-frame SVG are native
vector assets in assets/ui/scopes. Existing firearm/mechanical sounds and hit
feedback are reused by their established owners.

The canonical integration/fallback/quality rules are in ../../docs/ASSETS.md.
Never use the raw grid as proof that a pose fits the actual game viewport.
Inspect each frame in16:9, tall and wide windows, including flame nozzle points,
HUD/crosshair clearance and full hand/wrist/forearm continuity.
