# Smoke Pack42 — ZAP ZONE

Статус: полный комплект установлен и проверен в G:/МОЯ Веб-разработка/ZAP_ZONE, build834f3af971284de9. Интеграция выполнена по пользовательскому «продолжи» после показанных previews. Правила и semantic owners: docs/ASSETS.md, раздел «Дымовуха — Pack42».

17 runtime файлов перечислены в manifest.json с размерами, бюджетами и SHA256. Исходники создавались built-in image_gen. build_assets.py воспроизводит только resize/alpha-preserving cell derivatives и пять синтезированных WAV. Ранние smoke-action/clean и непаддированные world/near источники сохранены как отвергнутая provenance; runtime использует отдельные pin/windup/release/draw16:9 изображения и padded world. Near atlas строится из четырёх отдельных square sources; early near sheets сохранены как rejected provenance. Cloud/far sheets также отклонены после отдельных игровых кадров: обнаружены соседние фрагменты. Все6 timeline и6 far ячеек строятся из самостоятельных целых квадратных исходников с дополнительным transparent padding. Near/far/timeline не режутся из multi-cloud sheets. Full FPS canvases не tight-crop; recovery использует записанное точное окно первой empty-hand ячейки reload source.

FPS содержит готовые руки (baked-hands). Единственный слой переключается ready/action, procedural rig — fallback. Полёт принадлежит настоящему projectile, cloud art настоящему облаку, inside overlay фактическому присутствию игрока в дыме. Дополнительного RNG для разнообразия нет. Legacy7 files удаляются только после проверки замены; recovery хранится вне runtime.

Игровые кадры и машинные результаты находятся в evidence/, границы доказанности — VERIFICATION.md. Скриншоты атласа не заменяют реальные игровые проверки.
