# Weapon UI assets

Векторные SVG-ассеты для восьми слотов оружия ZAP ZONE.

- `pistol.svg` — пистолет
- `shotgun.svg` — дробовик
- `rifle.svg` — винтовка
- `rocket.svg` — ракетница
- `plasma.svg` — плазменное оружие
- `mine.svg` — мина
- `bomb.svg` — бомба
- `smoke.svg` — дымовуха

Ассеты созданы специально для интерфейса проекта, не требуют внешних картинок или шрифтов и имеют прозрачный фон. Если SVG не загрузится, игровой HUD автоматически оставит текстовое название оружия, поэтому механика игры не зависит от ассетов.
