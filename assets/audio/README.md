# ZAP ZONE audio assets

These WAV effects are original procedural audio generated specifically for ZAP ZONE from synthesized tones and deterministic noise layers. They do not contain third-party samples.

The library now covers weapon fire, explosions, ricochets, bullet whiz, Frontline capture feedback, open/tight acoustic tails, SR-9 supersonic crack, walk/run footsteps, and separate body/armor/head hit impacts.

Runtime spatializes remote sources, applies distance attenuation, selects environmental tails from map geometry, and keeps the previous Web Audio synthesis as a fallback when a file cannot be decoded or is not ready yet.
