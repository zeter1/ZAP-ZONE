# ZAP ZONE audio assets

These WAV effects are original procedural audio generated specifically for ZAP ZONE from synthesized tones and deterministic noise layers. They do not contain third-party samples.

The library covers weapon fire, explosions, ricochets, physical bullet whiz, Frontline capture feedback, acoustic tails, SR-9 supersonic crack, hit impacts, sampled weapon mechanics, battlefield ambience and multiple footstep surfaces.

Runtime spatializes remote sources, applies distance attenuation, selects environmental tails from map geometry, chooses footsteps from arena surface zones, and keeps Web Audio synthesis as a fallback when a file cannot be decoded or is not ready yet.

Combat Presence 1.2 expands this library to 28 validated WAV assets.
