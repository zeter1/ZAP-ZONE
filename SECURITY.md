# Security Policy

ZAP ZONE — browser-only WebGL game. Игра использует browser storage, внешнюю загрузку Three.js и выполняется внутри sandbox браузера.

## Как сообщить об уязвимости

Потенциально опасные детали лучше сначала отправлять приватно:

- Email: zeter11@gmail.com
- Telegram: https://t.me/zeter1

Укажите:

- затронутую revision/commit;
- браузер и версию;
- минимальные шаги воспроизведения;
- ожидаемый и фактический результат;
- влияние;
- безопасный proof-of-concept.

## Важные области

Особенно полезны сообщения о:

- XSS / script injection;
- небезопасной обработке browser storage;
- подмене или неожиданном выполнении внешнего CDN/script content;
- обходе ожидаемой browser sandbox-модели;
- утечке локальных данных или чувствительных диагностических материалов.

Не публикуйте cookies, токены, данные browser profile и другие секреты.
