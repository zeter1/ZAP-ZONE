#  ZAP ZONE

**ZAP ZONE** — браузерный 3D FPS на **Three.js/WebGL**: один игрок против 9 адаптивных ботов в режиме free-for-all.

Игра работает прямо в браузере и хранится в одном `index.html`: интерфейс, игровая логика, ИИ, оружие, эффекты и сохранения находятся в одном файле.

## Возможности

- 3D-арена на Three.js и WebGL.
- 1 игрок + 9 адаптивных ботов, каждый сам за себя.
- 8 типов оружия и снаряжения:
  - пистолет;
  - дробовик;
  - винтовка;
  - ракетница;
  - плазменное оружие;
  - мины;
  - бомбы;
  - дымовые гранаты.
- Стрельба, перезарядка, отдача, трассеры, гильзы и визуальные эффекты попаданий.
- Ракеты, мины и бомбы с радиусом поражения.
- Дымовые облака, влияющие на обзор.
- Система уровней и XP.
- Система улучшений с обычной, редкой, эпической и легендарной редкостью.
- Пути развития: штурм, точность, выживание, мобильность и взрывчатка.
- Броня, регенерация, критические попадания, вампиризм и другие модификаторы.
- Автосохранение прогресса в `localStorage` / `sessionStorage`.
- Восстановление игры после перезапуска страницы.
- Адаптация качества рендера под доступные CPU threads / device memory.
- Обработка потери и восстановления WebGL-контекста.

## Быстрый запуск

Для самого простого запуска скачайте репозиторий и откройте `index.html` в современном браузере.

Для более предсказуемой работы рекомендуется локальный HTTP-сервер:

```bash
python -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

## Установка через Git

```bash
git clone https://github.com/zeter1/ZAP-ZONE.git
cd ZAP-ZONE
python -m http.server 8000
```

## Требования

- современный браузер с WebGL;
- JavaScript должен быть включён;
- подключение к интернету при первом запуске необходимо для загрузки Three.js с CDN.

Проект подключает:

```text
three.js r128
```

через cdnjs.

## Архитектура

Сейчас проект intentionally сделан как автономное одностраничное приложение:

```text
index.html
├── CSS / HUD / меню
├── Three.js renderer и сцена
├── карта и коллизии
├── оружие и снаряды
├── эффекты и частицы
├── боты и AI
├── pickups
├── система XP и perks
├── autosave
└── главный игровой цикл
```

Это упрощает публикацию и перенос игры, но по мере роста проекта код имеет смысл разделить на независимые модули.

## Сохранения

Прогресс автоматически сохраняется в браузере. Сохраняются, в частности:

- уровень и XP;
- счёт и убийства;
- здоровье и броня;
- текущее оружие и боезапас;
- выбранные улучшения;
- позиция и направление игрока;
- cooldown мин, бомб и дымовых гранат.

Сохранение привязано к данным браузера. Очистка данных сайта / браузера может удалить прогресс.

## Производительность

Игра определяет доступные аппаратные ресурсы через браузер и при слабом устройстве включает облегчённые настройки, включая уменьшение части графических эффектов.

## Диагностика

Если игра не запускается или отображается неправильно:

1. откройте DevTools браузера (`F12`);
2. проверьте вкладку **Console**;
3. убедитесь, что Three.js загрузился с CDN;
4. проверьте поддержку WebGL;
5. попробуйте запуск через локальный HTTP-сервер вместо прямого открытия файла.

## Ограничения

- Основной интерфейс и управление в текущей версии ориентированы на ПК.
- Three.js загружается с внешнего CDN, поэтому полностью офлайн-запуск требует локальной копии библиотеки.
- Код пока находится в одном крупном HTML-файле.
- Автоматизированных браузерных тестов и CI в репозитории пока нет.

## Проверка

Минимальная ручная smoke-проверка после изменений:

1. загрузка до 100%;
2. старт игры и захват указателя мыши;
3. движение / прыжок / стрельба;
4. переключение оружия `1–8`;
5. перезарядка;
6. использование мины, бомбы и дымовой гранаты;
7. получение XP и выбор улучшения;
8. пауза и продолжение;
9. перезагрузка страницы и восстановление автосохранения.
